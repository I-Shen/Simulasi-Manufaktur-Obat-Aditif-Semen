Sub-folder proyek mandiri dalam repositori untuk memuat visualisasi tekno-ekonomi dan rekapitulasi proposal investasi lini produksi PCO (*Precipitated/Processed Chemical Oil/Oxide*).

## 📊 Parameter Model Terbaru (Berdasarkan CPO.txt)

1. **Investasi (Capex):**
   - 4 Unit Mesin (@ Rp 900 Juta) = **Rp 3,60 Miliar**
   - Pembangunan Gudang = **Rp 1,40 Miliar**
   - **Total Investasi = Rp 5,00 Miliar**

2. **Kapasitas & Produksi:**
   - Kapasitas sebelum yield = **30 Ton / hari** (30.000 kg/hari)
   - Yield produksi = **70%**
   - Produk jadi setelah yield = **20 Ton / hari** (20.000 kg/hari)
   - Jam operasi per hari = **21 jam** (3 Shift kontinu)
   - Hari kerja per bulan = **26 hari**
   - **Total Produksi per bulan = 520.000 kg (± 520,00 Ton)**

3. **Harga Jual & Omzet:**
   - Harga jual = **Rp 8.300 / kg**
   - **Omzet per bulan = Rp 4.316.000.000 (Rp 4,32 Miliar)**

4. **Struktur HPP:**
   - Raw Mat efektif = **Rp 2.000 / kg**
   - Biaya produksi = **Rp 2.000 / kg**
   - Sewa gudang = **Rp 487 / kg**
   - **Cash HPP = Rp 4.487 / kg**
   - Depresiasi (5 Tahun garis lurus) = **Rp 160 / kg**
   - **Full HPP = Rp 4.647 / kg**

5. **Profitabilitas:**
   - Laba per kg = **Rp 3.653 / kg (Margin 44,01%)**
   - **Laba per bulan = Rp 1.899.560.000 (Rp 1,90 Miliar)**
   - **Laba per tahun = Rp 22.794.720.000 (Rp 22,79 Miliar)**
   - **Payback Period = ± 2,6 Bulan (0,22 Tahun)**
